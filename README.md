# The Most simple dotfiles that ever created

> *"Hey buddy! This is my first repo on GitHub."* 

Welcome to my personal dotfiles! This repository contains my custom configurations for **Hyprland**, **Hyprlock**, **Waybar**, and **Rofi**.

---

### ⚠️ System Requirements

> [!IMPORTANT]
> **Arch Linux Only:** This configuration is strictly made and tested for **Arch Linux**. It may not work properly out-of-the-box on other Linux distributions!

---

### 💡 About This Config

* **Config Language:** Written entirely in **Hyprlang**.
* *Note:* I'm using Hyprlang because I honestly don't know how to use Lua... sorry about that! :p

---

### 📦 Dependencies (Yêu cầu cài đặt)

Before applying these dotfiles, make sure you have all the required packages installed on your Arch system:

```bash
sudo pacman -S hyprland hyprlock waybar rofi-wayland
