> *"Hey buddy! This is my first repo on GitHub."* 👋

Welcome to my personal dotfiles! This repository contains a simple, clean, and lightweight setup for **Hyprland** and its ecosystem.

---

> [!IMPORTANT]
> **Arch Linux Only:** This configuration is strictly tailored and tested for **Arch Linux**. It might not work out-of-the-box on other Linux distributions!

---

## 💡 About This Config

* **Config Language:** Written entirely in **Hyprlang**.
* *Note:* I'm using Hyprlang because I honestly don't know how to use Lua... sorry about that! :p

---

## 📦 Components

| Component | Tool | Description |
| :--- | :--- | :--- |
| **Window Manager** | [`Hyprland`](https://hypr.land) | Dynamic tiling Wayland compositor |
| **Lockscreen** | [`Hyprlock`](https://wiki.hypr.land/Hypr-Ecosystem/hyprlock) | Fast and modern lockscreen |
| **Status Bar** | [`Waybar`](https://github.com/Alexays/Waybar) | Highly customizable Wayland bar |
| **Launcher** | [`Rofi`](https://github.com/lbonn/rofi-wayland) | Application launcher (Wayland fork) |

---

## 🛠️ Installation

### 1. Install Dependencies

Install all required packages via `pacman`:

```bash
sudo pacman -S hyprland hyprlock waybar rofi-wayland

```
